Five observability surfaces. One binary.

Self-hosted analytics, errors, logs, traces, and session replays in a single 26 MB Go binary. Runs on a $5 VPS. MIT-licensed. No Kafka, no Clickhouse, no Kube.

Install in 60 seconds Try the demo →
curl -sL https://observe.dev/install.sh | sh

Everything you'd stitch together with four SaaS bills

Analytics

Pageviews, visitors, funnels, retention, journeys. UTM + campaigns breakdown. World map. Comparison mode.

Errors

Grouped issues with source-maps, breadcrumbs, releases, and alert rules. Sentry-shim SDK drops in with one import.

Logs

Search + filters + live tail over Server-Sent Events. Volume histogram. Structured attributes.

Traces (OTLP)

OpenTelemetry ingest, RED metrics per service, waterfall + flame graph, service dependency map.

Session replay

DOM snapshot + mouse + clicks + scroll + inputs. Playback with scrub and 0.5×–4× speed.

Flags & experiments

Targeting rules + rollout %, change-log audit, A/B with Bayesian probability-to-beat-control.
